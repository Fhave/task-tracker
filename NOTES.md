# Notes

## Three Improvements and Why

1. **Add a task status tracker**

   Include **Not Started**, **In Progress**, and **Completed** statuses. This gives users a clearer view of each task's progress than the current done/active checkbox.

2. **Allow editing priority and due date**

   Let users change a task's priority and due date after creating it. This makes it easier to keep task details accurate as plans change.

3. **Allow selecting and deleting multiple tasks**

   Add checkboxes and a bulk-delete action. This saves time when users need to remove several tasks instead of deleting them one at a time.
